# Support and feedback

Thank you for taking the time to share your experience with Autojobs. Clear feedback helps improve the app without losing its user-first, careful approach.

## Where to ask

| Need | Best place |
| --- | --- |
| Installation, setup, or everyday-use help | Start with the [README](./README.md) and [plain-language guide](./README.txt). Use GitHub Discussions when they are enabled. |
| A reproducible defect | Use the [bug report form](../../issues/new/choose). |
| A feature or workflow improvement | Use the [feature request form](../../issues/new/choose). |
| A security vulnerability | Follow [SECURITY.md](./SECURITY.md). Do not post it publicly. |
| A code or documentation contribution | Read [CONTRIBUTING.md](./CONTRIBUTING.md) and open a pull request. |

## Helpful details for a bug report

Good reports help maintainers understand the problem without needing access to your account. Include:

- The Autojobs version or commit
- Your Windows version and Chrome version
- Whether you installed the release, portable ZIP, or source version
- The steps that led to the problem
- What you expected and what happened instead
- Sanitized relevant lines from `autojobs.log` or `applications.csv`

Use Supervised mode for a first reproduction whenever possible. It makes unexpected questions and browser behavior easier to inspect safely.

## Please protect your privacy

Never attach or paste:

- Passwords, authentication codes, browser cookies, or session data
- Resume or CV files
- Personal addresses, phone numbers, email addresses, or answers to sensitive questions
- Private job application content or unredacted screenshots

Before sharing a log, remove names, URLs containing private identifiers, contact details, and other information that could identify you or a third party.

## Ways to help

You do not need to write code to make a meaningful contribution. You can:

- Describe where the first-run experience felt unclear
- Suggest more understandable wording or examples
- Report an accessibility issue
- Test a release on a supported Windows and Chrome setup
- Improve documentation or translations
- Review an open pull request
- Star or watch the repository to help others find it

Thank you for helping keep Autojobs practical, transparent, and respectful of people's choices.
