AUTOJOBS ANSWER-PROFILE GENERATOR PROMPT
======================================

TASK
----
You are preparing an importable autojobs answer profile using the resume/CV PDF uploaded with this prompt.

DELIVERY REQUIREMENT: create and attach/download a real file named exactly:
import_me_on_autojobs.json

The file contents must be valid JSON only. Do not put markdown fences or explanatory text inside the file. If your current ChatGPT interface can create files, ALWAYS create the file instead of merely pasting JSON into chat.

CORE RULES
----------
1. Use every factual detail supported by the resume/CV, including conservative logical or mathematical deductions that follow directly from those facts. The goal is to fill as much of the answer profile as can be truthfully established, not only sentences copied verbatim from the CV.
2. You MAY derive non-sensitive facts when the derivation is reliable. Examples: calculate experience duration from dated roles without double-counting overlapping periods; derive graduation year from a dated degree; normalize a clearly stated contact location into city/region/country; expand an unambiguous geographic abbreviation; combine address components into a complete location.
3. LOCATION IS IMPORTANT. If the CV states a current/contact location, produce the most complete factual form that can be safely established. Example: "Dublin, Ireland" may become "Dublin, County Dublin, Ireland"; "Santos, SP, Brazil" may become "Santos, São Paulo, Brazil". Populate current_location, city, county/region, country, address and postal_code when those components are supported. Do NOT infer current residence merely from a past employer, university, client, or project location.
4. Fill all non-sensitive profile fields that can be established from the CV: names, contact details, URLs, education, certifications, employers, skills, factual experience indicators, role/industry/support/leadership experience, languages when explicitly evidenced, and dated experience calculations when reliable.
5. If a fact cannot be supported or reliably derived, use an empty string: "". Never invent employers, dates, degrees, certifications, technologies, metrics, salary, notice period, availability, driving licence, security clearance, or other unsupported facts.
6. Work authorization, citizenship, nationality, visa/permit status, Irish Stamp, sponsorship need, and similar legal/immigration facts must be explicit in the CV or other user-provided factual material. Do not infer them from location, employer, language, name, or education.
7. For social/diversity/sensitive questions, do not infer anything from names, photos, pronouns, schools, countries, languages, addresses, or other indirect signals. Leave the answer blank unless the user explicitly provided that fact for this purpose. Prefer privacy over guessing.
8. For Yes/No or multiple-choice questions, use an exact listed choice when the CV clearly supports it. Otherwise leave it blank.
9. For free-text answers, be professional, polite, concise, factual, and directly relevant. EACH individual answer must be 230 characters or fewer, including spaces.
10. Avoid exaggerated claims, buzzword stuffing, first-person boasting, unsupported seniority, or invented metrics.
11. When calculating years of experience from dates, use the actual timeline and avoid double-counting overlapping jobs. If a technology is tied to a clearly dated role/project, you may derive a conservative duration. If dates are ambiguous, leave the numeric answer blank.
12. For generic factual free-text fields such as cover_note, why_fit, or achievement, you may create a short professional answer using only demonstrated CV facts. Leave role/company-specific motivation fields blank when the job/company context is not supplied.
13. Keep every key listed in the catalog below, even when the answer is blank.
14. learned_answers must be an empty object unless the user separately provided exact recruiter questions and answers.

REQUIRED FILE CONTENTS
----------------------
The file import_me_on_autojobs.json must contain an object exactly in this general structure:
{
  "schema": "linkedin-easy-apply-answer-profile",
  "version": 2,
  "defaults": {
    "numeric": "0",
    "text": "N/A",
    "boolean": "No",
    "social_question_strategy": "prefer_not_to_say"
  },
  "profile_answers": {
    "<every exact key from the catalog below>": "<answer or empty string>"
  },
  "learned_answers": {}
}

IMPORTANT: Do not omit blank questions. profile_answers must contain ALL catalog keys below exactly once.

ANSWER STYLE
------------
When a factual free-text response can be derived from the CV, make it sound like a strong but truthful job applicant: professional, polite, clear, and short. Never exceed 230 characters for a single answer.
