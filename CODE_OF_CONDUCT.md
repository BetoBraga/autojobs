# Code of Conduct

## Our commitment

Autojobs is a space for people who want to improve a useful, careful tool. We are committed to a welcoming environment where contributors and users can share ideas, ask questions, and disagree respectfully.

## Expected behavior

We ask everyone to:

- Be kind, constructive, and patient.
- Focus criticism on ideas, behavior, and code rather than people.
- Welcome different levels of technical experience and different job-search circumstances.
- Respect privacy and remove personal data from public project spaces.
- Accept feedback and help keep discussions practical and safe.

## Unacceptable behavior

The following is not welcome:

- Harassment, threats, insults, hate speech, or sexualized language
- Doxxing or sharing another person's private information
- Deliberately posting credentials, sessions, resumes, or other sensitive personal data
- Pressuring people to bypass platform protections or account-security controls
- Publicly disclosing a security issue before maintainers have had a reasonable opportunity to assess it

## Reporting a concern

For project-specific conduct concerns, contact the repository owner privately using the contact method on their GitHub profile. If content on GitHub creates an immediate safety concern, use GitHub's built-in reporting tools as well.

Reports will be handled with care and only shared when needed to understand and address the concern.

## Enforcement

Maintainers may clarify expectations, edit or remove content, issue a warning, limit participation, or remove someone from project spaces when necessary to protect the community.

## Scope

This Code of Conduct applies in project spaces, including issues, pull requests, discussions, and other public interactions representing Autojobs.
